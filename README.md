# 食光旅行（複刻原型）

以 PixiJS + TypeScript 製作的合成料理小遊戲，靈感來自手機遊戲《食光旅行》（Tasty Travels: Merge Game）。只複刻玩法機制，圖示為自繪的漫畫風 SVG。

**線上遊玩：<https://tatamochang.github.io/food-travel/>**（手機瀏覽器優先，直向版面）

## 遊戲說明

### 基本玩法

1. 棋盤最上排是「料理台」（左 5 格）和「調味區」（右 1 格），放著產出器。點一下產出器，消耗 1 點電力，在下方最近的空格產生食材或調味料。
2. 拖曳兩個相同的物品到一起，合成為下一階。料理階段為 A → B → C → D → E，E 是最終型態。
3. 拖到空格是移動，拖到不同的物品上是交換位置。產出器不能拖動，物品也不能放到最上排。
4. 棋盤上湊齊訂單需要的物品後，按「交付」，物品會一次從棋盤扣除並獲得獎勵。

### 三種料理

| 料理 | 產出器 | A | B | C | D | E |
|---|---|---|---|---|---|---|
| 義大利披薩 | 麵粉袋 | 麵團 | 披薩餅皮 | 番茄醬餅皮 | 起司披薩生胚 | 瑪格麗特披薩 |
| 日本壽司 | 米桶 | 白飯 | 飯糰 | 握壽司 | 壽司拼盤 | 豪華壽司船 |
| 法國可頌 | 奶油盒 | 奶油塊 | 酥皮麵團 | 可頌生胚 | 烤可頌 | 可頌早餐盤 |

一開始只有披薩，其他料理要靠劇情解鎖。

### 調味料與特製料理

調味產出器放在調味區，產出 1 等調味料；兩個同等級的調味料合成升一等，3 等為最高。

| 產出器 | 1 等 | 2 等 | 3 等 | 解鎖 |
|---|---|---|---|---|
| 鹽罐 | 粗鹽 | 細鹽 | 頂級海鹽 | 完成劇情第 2 關 |
| 香料罐 | 乾香草 | 綜合香料 | 秘製香料 | 完成劇情第 3 關 |

把調味料拖到對應的料理上（或反過來），兩樣都會消耗，變成特製料理。特製料理不能再合成，只能拿去交付訂單。下表是日常食譜，調味料解鎖後就能直接合成：

| 調味料 | 料理 | 特製料理 |
|---|---|---|
| 綜合香料 | 番茄醬餅皮（披薩 C） | 香料披薩 |
| 秘製香料 | 起司披薩生胚（披薩 D） | 秘製起司披薩 |
| 細鹽 | 握壽司（壽司 C） | 鹽燒握壽司 |
| 頂級海鹽 | 壽司拼盤（壽司 D） | 海鹽壽司拼盤 |
| 細鹽 | 可頌生胚（可頌 C） | 海鹽可頌 |
| 秘製香料 | 烤可頌（可頌 D） | 香草奶油可頌 |

### 食譜

點右上角「📖 食譜」查詢：

- **日常食譜**：已解鎖料理與調味料的合成路線，以及上表的調味料理。隨劇情解鎖。
- **特別食譜**：解鎖前不能合成，解鎖後隨機訂單也會開始要求，獎勵較高。

| 等級 | 食譜 | 配方 | 取得方式 | 訂單獎勵 |
|---|---|---|---|---|
| 🟢 | 鹽烤飯糰 | 粗鹽 + 飯糰 | 任務「飯糰達人」：製作 5 個飯糰 | ×2 |
| 🟢 | 香草麵包棒 | 乾香草 + 披薩餅皮 | 任務「熱門小店」：累計交付 10 張隨機訂單 | ×2 |
| 🟢 | 鹽奶油酥皮 | 粗鹽 + 酥皮麵團 | 任務「酥皮職人」：製作 5 個酥皮麵團 | ×2 |
| 🟢 | 香料飯糰 | 乾香草 + 飯糰 | 任務「調香師」：製作 3 個綜合香料 | ×2 |
| 🟢 | 炙燒香料握壽司 | 綜合香料 + 握壽司 | 任務「人氣名店」：累計交付 30 張隨機訂單 | ×2 |
| 🟠 | 松露瑪格麗特 | 秘製香料 + 瑪格麗特披薩 | 高等任務「披薩大師」：製作 3 個瑪格麗特披薩 | ×3 |
| 🟠 | 黃金可頌塔 | 頂級海鹽 + 可頌早餐盤 | 商店購買 🪙800 | ×3 |
| 🔴 | 帝王壽司船 | 秘製香料 + 豪華壽司船 | 集齊 3 個 Boss 關碎片 | ×5 |

「製作」指在棋盤上合成出來。任務進度在食譜頁面的特別食譜裡查看，達成就自動解鎖。

### 料理台、調味區與倉庫

- 料理台放料理產出器（麵粉袋、米桶、奶油盒），共 5 格：一開始開 1 格，通過第 1、11、21、29 關各開 1 格。
- 調味區放調味產出器（鹽罐、香料罐），只有 1 格，兩種調味產出器要輪流換上去。
- 台上放不下的產出器會進「倉庫」，容量不限。點右上角「倉庫」可以把台上的產出器「收回」，或把倉庫裡的產出器「放入」空格，用來換位。
- 點台上的空格會打開倉庫，點有鎖頭的格子會提示第幾關開放。

### 訂單

- **劇情訂單**：共 30 關，每關有固定需求，全部湊齊才能交付並進入下一關。獎勵金幣與電力，完成特定關卡會解鎖新料理、調味料和料理台格子。第 11 關起會要求特製料理。
- **Boss 關**：第 10、20、30 關，紅框卡片，需求較多，獎勵大量金幣和 1 個食譜碎片。
- **隨機訂單**：同時有 3 張，只會要求已解鎖的料理，需求 1 到 2 種物品。關卡越後面，要求的階數越高。從劇情第 3 關起，也會要求日常食譜的特製料理（獎勵 ×1.5）；特別食譜解鎖後也會出現（×2／×3／×5）。只會出現做得出來的料理。交付後獲得金幣，並自動補上新訂單。
- 交付按鈕只有在棋盤上物品足夠時才能按。如果兩張訂單需要同一批物品，交付其中一張後，另一張可能就不能交付了。

### 電力

- 基本上限 20，每 60 秒自然回復 1 點（離線期間也會回復）。
- 劇情訂單會獎勵電力，商店也能購買。
- 買來或獎勵的電力可以超過上限，超出的部分不會自然回復。

### 商店

點右上角「商店」。可以用金幣購買：

- **電力**：小電池、電力罐、電力箱。
- **永久提高上限**（各限買 1 次）：大容量電池（+5）、超級電池（+10）。
- **暫時提高上限**：咖啡加持（+10，30 分鐘）、美食節狂歡（+20，2 小時）。重複購買會延長時間。
- **食譜**（限買 1 次）：黃金可頌塔食譜（800）。

商品比較多時，商店清單可以上下拖曳或用滑鼠滾輪捲動。

### 存檔

進度存在瀏覽器的 localStorage，會自動儲存。換裝置或清除網站資料會歸零。

舊版存檔（還沒有料理台的版本）讀取時會自動轉換：原本最上排的料理移到棋盤空格，棋盤滿了就暫存進倉庫，可以之後再「放入」；棋盤上的產出器搬到料理台或調味區，放不下的進倉庫。舊版只有 5 關，關卡進度照原本的關數保留。已經通過的關卡若有新的解鎖（例如鹽罐、香料罐），也會補發。

## 開發

需要 Node.js 22 以上。

```bash
npm install
npm run dev     # 開發伺服器 http://localhost:5173
npm test        # 單元測試（vitest）
npm run build   # 型別檢查並產生 dist/
```

圖示由 `scripts/gen-icons.mjs` 產生（共用描邊、陰影、高光規則），修改後執行 `npm run icons` 重新產生 `src/assets/icons/*.svg`。

VS Code 內按 F5 可直接除錯：「Debug game (Chrome)」會自動啟動開發伺服器並開啟 Chrome，「Debug tests (vitest)」可對測試下中斷點。

push 到 `main` 會觸發 GitHub Actions 跑測試、build，並部署到 GitHub Pages。
