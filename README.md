# 食光旅行（複刻原型）

以 PixiJS + TypeScript 製作的合成料理小遊戲，靈感來自手機遊戲《食光旅行》（Tasty Travels: Merge Game）。只複刻玩法機制，美術為色塊與文字佔位。

**線上遊玩：<https://tatamochang.github.io/food-travel/>**（手機瀏覽器優先，直向版面）

## 遊戲說明

### 基本玩法

1. 棋盤上有「產出器」。點一下產出器，消耗 1 點電力，在最近的空格產生 A 階食材。
2. 拖曳兩個相同的物品到一起，合成為下一階。階段為 A → B → C → D → E，E 是最終型態。
3. 拖到空格是移動，拖到不同的物品上是交換位置。
4. 棋盤上湊齊訂單需要的物品後，按「交付」，物品會一次從棋盤扣除並獲得獎勵。

### 三種料理

| 料理 | 產出器 | A | B | C | D | E |
|---|---|---|---|---|---|---|
| 義大利披薩 | 麵粉袋 | 麵團 | 披薩餅皮 | 番茄醬餅皮 | 起司披薩生胚 | 瑪格麗特披薩 |
| 日本壽司 | 米桶 | 白飯 | 飯糰 | 握壽司 | 壽司拼盤 | 豪華壽司船 |
| 法國可頌 | 奶油盒 | 奶油塊 | 酥皮麵團 | 可頌生胚 | 烤可頌 | 可頌早餐盤 |

一開始只有披薩，其他料理要靠劇情解鎖。

### 訂單

- **劇情訂單**：共 5 關，每關有固定需求，全部湊齊才能交付並進入下一關。獎勵金幣與電力，完成特定關卡會解鎖新料理和對應的產出器。
- **隨機訂單**：同時有 3 張，只會要求已解鎖的料理，需求 1 到 2 種物品。關卡越後面，要求的階數越高。交付後獲得金幣，並自動補上新訂單。
- 交付按鈕只有在棋盤上物品足夠時才能按。如果兩張訂單需要同一批物品，交付其中一張後，另一張可能就不能交付了。

### 電力

- 基本上限 20，每 60 秒自然回復 1 點（離線期間也會回復）。
- 劇情訂單會獎勵電力，商店也能購買。
- 買來或獎勵的電力可以超過上限，超出的部分不會自然回復。

### 商店

點右上角「商店」。可以用金幣購買：

- **電力**：小電池、電力罐、電力箱。
- **永久提高上限**（各限買 1 次）：大容量電池（+5）、超級電池（+10）。
- **暫時提高上限**：咖啡加持（+10，30 分鐘）、美食節狂歡（+20，2 小時）。重複購買會延長時間。

### 存檔

進度存在瀏覽器的 localStorage，會自動儲存。換裝置或清除網站資料會歸零。

## 開發

需要 Node.js 22 以上。

```bash
npm install
npm run dev     # 開發伺服器 http://localhost:5173
npm test        # 單元測試（vitest）
npm run build   # 型別檢查並產生 dist/
```

VS Code 內按 F5 可直接除錯：「Debug game (Chrome)」會自動啟動開發伺服器並開啟 Chrome，「Debug tests (vitest)」可對測試下中斷點。

push 到 `main` 會觸發 GitHub Actions 跑測試、build，並部署到 GitHub Pages。
